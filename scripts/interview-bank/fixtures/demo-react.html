React 里为什么会有闭包陷阱？

React 闭包 状态快照
  • 函数组件每次渲染都会形成新的作用域，回调捕获的是当次渲染时的值。
  • 异步逻辑、事件监听和定时器如果处理不好，就很容易读到旧状态。
  • 理解这一点后，再去谈 useRef、函数式更新或 effect 重绑才更稳。

Context 为什么容易把更新范围放大？

React Context 性能优化
  • 当 Context value 改变时，依赖它的消费组件都可能重新渲染。
  • 如果一个 Context 什么都管，更新影响面就会越来越大。
  • 拆分上下文、稳定 value 结构和缩小共享范围，是更稳的缓解思路。
